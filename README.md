# RockPaperScissors

RPS is a RockPaperScissors game with both a cil interface and gui interface with Tkinter, you can play it by clicking on the buttons or typing R P S , r p s on you keybord 

game.py --> all core logic

cli.py --> cli interface

gui.py --> gui interface
